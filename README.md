# MedSim XR - Phase 1-3 prototype (desktop + VR code path), expanded equipment set

A Unity 6 / URP hospital training prototype built on NVIDIA SimReady Assets. **Phases 1-2 (desktop) and Phase 3 (OpenXR project setup, VR rig, VR controls, desktop VR simulator) are built and
tested headless. No real headset has ever been connected. Phase 4 (Quest APK) is not started.**

> **Not clinically reviewed.** All training text, hints and explanations are generic educational summaries written for
> this prototype. Scoring weights and the pass threshold are provisional design choices. Nothing here has been validated
> by qualified healthcare professionals and it must not be used for formal training until it has been.

## What works today

- One 10 m x 8 m training room with four real NVIDIA SimReady assets (patient transport chair, CT injection system,
  corrugated supply box, storage rack) plus seven clearly labelled **placeholder** primitives (bed, vital-sign monitor,
  hand-hygiene station, waste container, supply cart, storage cabinet, inspection table).
- Desktop first-person controls, object highlight, inspect panel, grab / rotate / release / reset, a work-surface
  placement zone, drop detection, and an interaction event log.
- Module A, **Equipment Identification**: 10 data-driven questions, up to 3 attempts, hints, explanations,
  deterministic local instructor, configurable scoring, and a JSON + CSV session report.
- Names are hidden during the quiz (hover label, inspect panel and the world info panel) so they cannot give answers away.

## Equipment set

The room is laid out from `Data/Layout/layout.json` (generated by `Tools/AssetValidator/make_layout.py` from a slot table) and populated
only with NVIDIA SimReady assets whose model files were actually converted. Equipment entries live in `Data/Equipment/equipment.json`
(generated by `Tools/AssetValidator/add_hospital_assets.py`, which only emits entries whose GLB exists). Categories include patient care,
infection prevention, emergency, surgical instruments, imaging (X-ray components), robotics, safety and furniture. Every entry is flagged
`clinicalReview: pending`; descriptions are generic teaching summaries written for this prototype.

Module **F - Advanced Identification** (menu option 6) is a second identification quiz generated by `Tools/AssetValidator/make_advanced_quiz.py`
over the newer equipment. Its hints come from each item's category and real position in the layout, and names stay hidden during the quiz.

**Not delivered:** human anatomy, a skeleton and organ models, and a humanoid robot. The SimReady dataset contains none of them (the humanoid
robot was dropped at the user's request). BodyParts3D 4.0 (CC BY 4.0 per its current README) was identified as a source, but the server
throttles downloads to a few KB/s and the 143 MB archive was not completed. `Tools/AnatomyImport/fetch_bp3d.py` is a resumable parallel
downloader if you want to try again; no anatomy models are in the app.

## Controls (desktop)

| Key | Action |
|---|---|
| W A S D / mouse | Move / look |
| E | Inspect the object under the crosshair |
| Left click | Select (answers the current quiz task) |
| G | Grab / release a permitted object |
| Mouse wheel | Rotate the held object |
| R | Reset held (or looked-at) object to its start pose |
| F2 | Toggle the keyboard/mouse VR simulator (no headset needed) |
| Tab | Training menu: 1 A identify (core), 2 B safe handling, 3 C monitoring, 4 D infection prevention, 5 E CT quiz, 6 F advanced identification, 7 dashboard, 8 back |
| Q | Leave a running module (nothing recorded) |
| N | (Module C) report an out-of-range value; or click the monitor |
| H / X / Enter | Hint / skip task / continue (during the quiz) |
| Esc | Pause |

Fixed equipment (chair, CT unit, rack, furniture) is deliberately **not** grabbable. Only the supply box is.

## Run it

Requirements: Windows, Unity **6000.6.3f1** with URP, Blender 5.2 and Python 3 (for regenerating assets).

1. Open `D:\MedSimXR` in Unity Hub (first import is slow: package resolution + a ~10 minute script compile on an integrated GPU).
2. Open `Assets/Scenes/Hospital_Phase1.unity` and press Play.
3. To rebuild everything from the data files: menu **MedSim XR > Build All**.

Reports are written to `%USERPROFILE%\AppData\LocalLow\MedSimXR\MedSim XR\Reports` (Unity `persistentDataPath`).

### Regenerate the assets (optional - converted GLBs are already in `Assets/SimReady`)

```
hf download nvidia/simready-assets --repo-type dataset --include "chair_patient_mobile_a01/*" --local-dir Tools/AssetDownloader/raw
blender --background --python Tools/USDConverter/convert_usd.py -- <usd> <out.glb> <report.json> <target_tris> <tex_px>
python -I Tools/AssetValidator/build_manifest.py
```
`hf download` needs one `--include` pattern per call. `Tools/USDConverter/convert_all.ps1` batches the four assets.

### Run the tests

`powershell -File Tools\run_all_tests.ps1` rebuilds, runs the EditMode and PlayMode suites headless and writes
`Documentation/TestResults_*.xml`.

## Known issues and limitations

- Blender warned that the chair's `seat_01_mesh_00` mesh is "not valid" during export. It renders correctly in Unity.
- The rack's UDIM texture was flattened to its first tile.
- The CT injector is a visual teaching model only. Nothing about its operation, dosing or patient connection is simulated.
- Highlight is a world-axis box, so rotated objects get a loose volume.
- Editor script compile takes about 10 minutes on this machine (Intel UHD 620), so edit in batches.
- Machine has 15.9 GB RAM, not the 8 GB in the brief; low-memory behaviour is untested.

## VR controls (Phase 3, scripted-input verified only)

Right trigger select | right grip grab/release | A inspect or confirm | B reset | left X hint | left Y training menu |
menu button pause | left stick walk (or choose option in lists) | right stick X snap turn, Y rotate held object |
left stick click leave module | right stick click report an out-of-range value (module C).
Start with a headset by plugging it in with an OpenXR runtime active; `-novr` skips the attempt, `-vrsim` starts the simulator.
